🚀 STAR CATCHER CHALLENGE ⭐
A Space-Themed Star Catching Arcade Game Using Python and Pygame
📌 About the Project

STAR CATCHER CHALLENGE is a fun and interactive 2D arcade game developed using Python and Pygame.

In this game, the player controls a spaceship to catch falling stars and earn points. The player has three lives, and every missed star reduces one life. The objective is to catch as many stars as possible and achieve the highest score!

🎮 Features
🚀 Attractive spaceship design
⭐ Falling star collection gameplay
🌌 Beautiful animated space background
🎯 Real-time score tracking
❤️ Three lives system
✨ Particle effects when catching stars
📈 Increasing difficulty as the score increases
🔄 Restart option after Game Over
🎨 Colorful graphics and smooth gameplay

🎮 Game Controls
Key	Function
LEFT ARROW / A	Move spaceship left
RIGHT ARROW / D	Move spaceship right
R	Restart the game
ESC	Quit the game
📥 Installation
Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

Step 2: Install Pygame

Open Command Prompt or Terminal and execute:

bash
pip install pygame

Step 3: Download or Clone the Repository
bash
git clone https://github.com/YOUR-USERNAME/Star-Catcher-Challenge.git

Step 4: Navigate to the Project Folder
bash
cd Star-Catcher-Challenge

Step 5: Run the Game
bash
python main.py
